## Observações

- Os nomes são sugestões para padronizar os arquivos; confirme visualmente cada imagem antes de renomeá-la.
- Não inclua senhas, tokens ou credenciais reais.
- As imagens originais foram analisadas na conversa, mas ainda precisam ser adicionadas a esta pasta no GitHub.
- Não confundir os dois serviços FTP encontrados: `vsftpd 2.3.4` na porta `21/tcp` e `ProFTPD 1.3.1` na porta `2121/tcp`.
