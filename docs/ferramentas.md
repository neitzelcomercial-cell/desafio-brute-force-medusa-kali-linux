# Ferramentas utilizadas

## Kali Linux

Distribuição Linux voltada a testes de segurança e auditoria. Neste projeto, é o ambiente de trabalho a partir do qual serão realizados os procedimentos autorizados.

## Nmap

Ferramenta de reconhecimento de rede utilizada para identificar hosts ativos, portas abertas e serviços disponíveis. Os resultados específicos deste laboratório serão documentados a partir das saídas reais obtidas.

## Medusa

Ferramenta de auditoria de autenticação que permite testar combinações de credenciais em serviços compatíveis. Seu uso neste projeto deve ficar restrito ao laboratório controlado e autorizado.

## Registro dos comandos

Para cada comando utilizado, documentar:

1. Finalidade do comando.
2. Significado dos principais parâmetros.
3. Serviço ou host de laboratório ao qual foi aplicado.
4. Resultado observado.
5. Cuidados e limites de uso.

Os comandos e resultados concretos serão adicionados após conferência do histórico e das evidências, evitando registrar exemplos como se fossem execuções reais.
